# Goryeo Banquet A/B test (ITV) — README

## What this is

30-second 3-speaker scene at a Goryeo dynasty royal banquet, generated by:
- **MiniMax M3.0** (Hailuo-2.3 video + M3 TTS, "mmx speech") — local pipeline
- **Google Veo 3.1** — via the Veo 3.1 generateContent API

Headline finding: M3 ran the full 30s uncut (no refusal, no segmentation). Veo's visual fidelity (faces, clothing, steam, backgrounds) was judged "miles better" on first frame by the user — so the "M3 holds 30s vs Veo 8s" angle was not a real differentiator. See `requirements.md`, `ideation.md`, `plan.md` for the full decision history.

## Reproducing the test

The output files here are the artifacts. To regenerate, work from `royal-outcasts/`:

```bash
cd /Users/fuchitalee/development/royal-outcasts
# M3 pipeline (image-to-video, 3 clips, stitch):
python3 scripts/m3_banquet_30s.py
# Veo 3.1 reference (see plan.md for the exact referenceImages payload):
python3 scripts/veo_banquet_30s.py
```

Both scripts read character references and voice samples from `royal-outcasts/research/`. The locked prompt is in `royal-outcasts/m3-test/locked_prompt.txt` (also copied to this dir).
