# Updating reference documents

This page points to the project instructions for maintaining the human- and
agent-facing reference library:

[`updating-reference-docs` project skill](../../.claude/skills/updating-reference-docs/SKILL.md).

The skill explains how to keep references detailed, grounded in current
implementation, and linked to the right sources. The folder guide is in
[`docs-taxonomy.md`](../docs-taxonomy.md). That taxonomy is a draft until the
project owner reviews it.
