11/
But the gift has fine print. CrowdStrike saw that DeepSeek R1 writes up to 50% more insecure code if the request mentions Tibet or the Uyghurs. And a backdoor can survive retraining: Anthropic showed in 2024 that, if your new data never touches the trigger, the hidden behavior can remain there, even if you put the model through fine-tuning and RL.
