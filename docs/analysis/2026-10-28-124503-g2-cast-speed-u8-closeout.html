Why good stills are scarce

  • All 5 weak stills in attempt 4 were video frames, going by the collector's own grades. Every photo from a web page graded B− or better.
  • In round 0b the collector agreed with the grader. It flagged its own weak still after using both re-picks, so the grading wasn't the problem. It had no better candidate.
  • Grades near the C+/B− line flip between runs. The same LI Yanhong still was graded C+ once and B once. A borderline frame can pass one round and fail the next.
  • The candidate pool is thin. CHENG Yixiao had only 2 usable source items, so one still had to be a video frame. Each person lost 2–7 pages:
    • Zhihu, Tieba and some company sites answer with an HTTP error;
    • Baidu Baike links that contain raw Chinese characters are refused by the collector's own URL check before any download. This looks like a missing URL-encoding step. It's worth checking, but Baike also returned an HTTP error for an encoded link.

Possible directions for the fix (to plan, not yet decided)

  • When a video frame is caught mid-word, soft or with text near the face, try nearby frames from the same shot. The same face a second later is usually usable.

  • Percent-encode Chinese URLs before the URL check, and look for photo sources that don't block the collector.
  • Success measure: rerun the four test people a few times with no paid change between runs, and aim for nearly every pack to pass the bar (for example 11 of 12) before going back to the speed loop.
