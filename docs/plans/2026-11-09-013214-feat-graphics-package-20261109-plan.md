# Copy Editor-led Graphics Package - Plan

## Plain-English Summary

The owner accepted the seven-story trial on November 9: the workflow works; the headlines need separate improvement. This subplan is the coding handoff for that accepted workflow. Implement the tested sequence with production storage and recoverable jobs. Preserve the current headline contract and prompts as the starting point; better puns, a new headline model, extra ranking calls and headline-quality experiments are outside this work and are not conditions for completing it.

Copy Editor ranks the strongest headline as A and keeps B in reserve, with one shared article. Graphics prepares both treatments together and uses Grok Image 2.0 for the composed stills. A is the publication choice. B replaces it only after a definite A image/video failure; imperfect creative execution cannot cause a switch. During testing, generate both stills so the owner can inspect B too. Animate A with five-second Grok Imagine Video 1.5 Lite; animate B only on the technical fallback path.

There are no editorial approval gates. C1 ranking determines the primary headline; poor scores, weak likeness, imperfect lettering, evidence gaps, unknown credits or an unavailable reviewer do not stop publication. EIC supplies one scorecard for the admin after publication. The scorecard cannot hold, unpublish, rewrite or trigger a new paid attempt. No clearance card is required. Missing outputs or technical failures use saved fallbacks; an absent file or nonexistent story cannot be reported as successfully delivered.

The accepted normal production path uses **6 model calls**: C1, G0, G1, I-A, V1 and E1. G0 makes the first visual judgment even when it requests no search. Test mode additionally renders I-B, making **7 calls**. A definite A video failure may add V-B; the overall ceiling remains **8 calls** including discovery, both stills and both videos. There is no C2 selection call. At most two searches, four page fetches and four image downloads are separate tool requests. Zero creative rerolls; upstream harvesting and selection are additional.

Each selected story gets independent editorial work. The initial entry is a manual selection; future automated selection is outside this release. Two independently hosted creation workers and a separate review worker are the proposed redundancy; changing concurrency also requires replacing the current global single-flight restriction with bounded, per-run claims. Video polling releases the worker between polls. A failed run cannot reserve the whole newsroom indefinitely. No finite setup can guarantee on-time delivery during a shared database, broker or provider outage; durable pending work and reconciliation prevent silent loss.

The accepted workflow is deployed and verified on staging. The owner now directs production deployment; integrate the staged Graphics behavior with current production, preserving live collection and existing editorial work.

### Production Pseudocode

All helper names below describe proposed responsibilities. This is logical stage order, not one long Celery task: each provider phase executes as a separate bounded task, saves its outcome, and dispatches the continuation. The150-second hard limit applies to one such task, not the whole package. Reuse the real reference reader, source storage, shared publisher and accounting rather than adding parallel implementations.

```python
def advance_package(request, test_render_reserve=False):
    run = materialize_or_resume_interval(request)
    draft = attempt_once("C1", rank_two_heads_and_write_shared_article, request)
    if not draft.has_publishable_fields:
        return publish_caller_copy_if_present_else_record_no_output(run)
    sources = reuse_existing_source_and_identity_images(request, draft)
    discovery = attempt_once("G0", decide_approaches_and_plan_search, draft, sources)
    sources += bounded_search_and_fetch_if_available(discovery)
    design = attempt_once("G1", prepare_both_treatments, draft, sources, discovery)
    a = render_once_if_prepared("I-A", design.A)
    reserve_job = enqueue_once("I-B", design.B) if test_render_reserve else None
    # Testing observes B independently; publication/video never joins its completion.
    edition = publish_saved_c1_copy_once(draft.A, draft.article, a)
    video = submit_or_resume_once("V1", a) if a.exists else None
    # These continuations are short durable tasks, not a blocking worker loop.
    if a.definite_failure or (video and video.definite_failure):
        b = resume_or_render_once("I-B", design.B, reserve_job)
        if b.exists:
            edition = record_explicit_media_failure_fallback(edition, draft.B, b)
            video = submit_or_resume_once("V-B" if video else "V1", b)
    # Pending/ambiguous results retain the current edition and saved provider ID.
    attach_matching_available_outputs(edition, video)
    enqueue_once("E1", review_current_saved_revision_for_admin, edition)
    return actual_saved_package_state(edition)
```

Each helper checks the inherited deadline/allowance, claims the stage once, saves exact requests and sends outside a transaction. Polls release production workers; a definite provider failure is distinct from a timeout or unknown acceptance. Save original A copy before video, preserve immutable revisions on explicit technical fallback, and reject stale callbacks. No quality score or visual preference can activate B. The local runner uses files and bounded polling; production durability remains U1–U7 work.
