## Plain-English Summary

One slow request occupied the only web worker serving page HTML, stylesheets, chart updates and health checks. Production database logs identified a 33-second enrichment query that also prevented a commentary request from committing. The repair limits the claim lock to the queue entry and configures a second web worker. A page can retry a failed local stylesheet or deferred script twice. If a visitor deselects Meta while the scripts are recovering, the chart uses that choice and retries a gateway error once. A real PostgreSQL transaction, an occupied web worker and fresh Chromium sessions exercise these failures.
