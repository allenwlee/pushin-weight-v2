## Technical Decisions

The default Django caches in `project/settings.py` are process-local/file-local and cannot survive separate Render cron processes. `core.models.CallState` stores a per-query watermark, not a global provider-health decision; `CollectionRun` is an immutable execution record, not an atomic mutable breaker. Add one small typed `SearchProviderCircuit` table and one migration; zero tables retired. Each circuit is keyed by provider, endpoint family and credential purpose when applicable, and owns its failure count, open deadline and probe lease. Use atomic transactions and short bounded leases; do not hold DB locks over HTTP. Use database time or injected clock in tests. No JSON fields are added. At runtime this state must be written to the application DB; this task does not write or migrate production.

Count empty success only on an explicitly identified expected-nonempty search (for example, a bounded probe with a demonstrated positive or a continuation claiming further pages); ordinary empty searches are valid and must not trip the breaker. Never send a TwexAPI cursor to TwitterAPI or the reverse. An ambiguous empty must not advance a coverage cursor. Rate-limit physical TwexAPI starts across processes (trial minimum six seconds configurable) with a durable reservation; 429 honors Retry-After within the cycle deadline, with bounded attempts and no retry storm. The TwexAPI route requires its secret; the distinct TwitterAPI.io keys can still fall back independently when that secret is absent.

Official API contract: [TwexAPI OpenAPI](https://twexapi.io/openapi.json), `/twitter/advanced_search/page`, `AdvancedSearchCursorQuery`, `AdvancedSearchCursorResponse`, and `TweetModel`. The advertised page size is up to 20. Treat plan-dependent rate and price as configuration/owner decisions, not hardcoded current facts.
