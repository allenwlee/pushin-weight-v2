home page. Keep the production Chart.js chart, feed, endpoints, data contracts,
headline, filters, and all other chrome unchanged. Correct the subsequent
staging-review failures in pulse localization, compressed window-control
layout, and the 30-day chart request without changing those product contracts.

### Approved targets

| Surface | Required behavior |
| --- | --- |
| Locale buttons | `en`, `zh-cn`/`中文`, and `original`/`原文` retain identical button geometry while labels change. |
| Time-window buttons | All four buttons retain identical geometry across English, Chinese, and original modes. The one-day label is `1d` in English/original and `1天` in Chinese. |
| Pulse chips | Each selected chip uses the same blue accent as the active time-window control. Chips toggle independently; selected brands are the union sent to both production chart and feed requests; deselecting the last chip restores all brands. |
| Timezone pill | Local and California times are always visible in 24-hour format, separated by one thin divider. Local is selected initially. | Pulse heading | English/original show `Trending · 1d heat`; Chinese shows `脉冲 · 1天热度`. |
| Compressed windows | All four time-window buttons, including `365d`/`365天`, remain visible and non-overlapping at mobile and compressed-desktop widths. |
| 30-day request | The ordinary 30-day chart request completes without exhausting the web worker timeout; its chart, pulse, and Top Voices payload contracts remain unchanged. |
