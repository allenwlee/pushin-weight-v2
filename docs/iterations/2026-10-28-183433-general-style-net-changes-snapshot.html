Homepage in General's style: net changes for production

Final state only. Changes that were tried and then reversed are left out (bronze/LinkedIn colors, removing every heading, the bronze logo, the glow, the automatic glow cycle, the Christmas-light animation). Source: docs/brainstorms/2026-10-22-184545-homepage-general-style-owner-requests.md. This file is updated after every prototype change. Last updated 2026-10-27 (owner item 36).

1. Layout and look

  1. Use General's styling: DM Sans text, Newsreader headlines, blue #4378ff, ink #18212d, 18px rounded panels, General's breakpoints, 1440px max width.
  2. Page background is Facebook gray #f0f2f5. Panels, cards, chips, filter buttons and the side rail stay white.
  3. Left icon rail as on General (General link, Trending, Posts by brand, Trend summary, Latest, Pro), with black icons. It becomes a slide-out drawer on phones.
  4. Masthead: white, full width, then labelled Window, Clock and Language controls. Logo: the line-traced ten-sided weight drawn with 1 px lines, also used for the rail's General icon and the browser-tab icon (owner item 30). Where each handle leg meets the top of the weight, the seam is curved (front half of an ellipse) so the round handle reads as attached (owner item 39). To its right, PUSHINWEIGHT on one line in italic DM Sans capitals, 15px, all ink: PUSHIN medium (500, letter spacing 0.06em), WEIGHT extra-bold (800); no apostrophe and 走个量 removed (owner items 31–36, locked in by item 39). The browser-tab title and the side drawer label are PUSHINWEIGHT. This logo is final (owner item 40). The SVG is in .context/compound-engineering/ce-prototype/2026-10-26-decagon-line-logo/assets/.
  5. Trending models bar is a white panel with no heading.
  6. Filters row is labelled "Filters", with General-style pill buttons and dropdowns.
  7. Main grid: Trend summary on the left in General's story style, the wider "Posts by brand" chart panel keeps its heading. On narrow screens: chart, then summary, then feed.
  8. Feed is a panel that keeps its heading, with posts as a grid of white cards.
  9. No bronze anywhere. Former amber/bronze status labels become muted gray. Mixed-sentiment and official-role icons use amber #d97706.
  10. Public launch version 1.0.0b1 with the internal version in parentheses: footer "Made with ❤️ in Yokohama. v1.0.0b1 (0.3.0)." The public version is a separate product label; the internal version stays the package version (pyproject.toml, git tags) and keeps its own sequence from 0.2.0b1. Next internal number not yet chosen (0.3.0 is an example). Update the footer, README and footer test. A "Beta" badge beside the masthead logo is recommended; wording not yet confirmed.

4. Posts-by-brand chart

  1. No hover tooltip.
  2. Hovering a legend entry or anywhere along a line focuses that brand: bold name, its post counts drawn above its points, other lines dimmed to 24% and other legend entries to 56%. Keyboard focus does the same.
  3. Desktop: click a line or legend entry to pin the focus; click elsewhere to release. Phones: tap to focus, tap again or elsewhere to clear.
  4. Beacons on every line from page load, never stopping: at each line's current point (the latest time slot; on 1 day, 0 at the right edge when the latest 5 minutes had no posts), a solid shape in the brand's beacon shape plus a copy that expands 1× to 4× while fading, repeating every 2.25 s with no pause. Dimmed brands' beacons keep pulsing at 24%. Still shape only for viewers who prefer reduced motion. The focused brand's legend shape pings in the same rhythm.
  5. Y axis on the right, with no axis line.
  6. Lines end 16px short of the right axis so the latest point and beacon are clear.
  7. Smooth monotone curves on every view.
  8. No point markers. Clicking the 1-day chart still narrows the feed to a 5-minute slot.
  9. Lighter dotted gridlines (1px dots, 3px gaps, #dfe4ec).
  10. 1-day lines are at least 1.75px wide so the patterns show. The live "today is partial" dashed last segment on 7/30/365 days is kept only for solid-pattern brands.
  11. The canvas gets its own fixed-height box (300px desktop / 240px / 200px phone) instead of the forced 220px height.
  12. 1-day lines end at the last 5-minute bucket the harvest has fully searched, so the end points and beacons show real counts instead of the empty, not-yet-searched final minutes. The axis's last tick is that bucket's end. Needs the last harvest time in the chart payload (not there today). 7/30/365-day views unchanged.
  13. The focused line (hovered, pinned or keyboard-focused) draws solid whatever its resting pattern, including the partial last day, and returns to its pattern when focus clears. The legend swatch keeps the resting pattern.

5. Axis, times, numbers and copy by language

  1. 1-day axis ends at the time of the latest fetch (the chart payload's fetched_at) and steps back whole hours from it (10:03pm, 8:03pm, …): every hour when the chart is wide enough, otherwise every 2 hours (at 1440px desktop width it is every 2 hours). Each 5-minute bucket is drawn at its end time, so the line's last point is the fetch time. The California/Beijing row uses the same positions. The row labels read "Local" and "CA".
  2. 7/30/365-day axis dates per language: English "Oct 18" (7d, 30d) and "Dec 2025" (365d); Chinese and Japanese "10月18日" and "2025年12月". The last tick is the latest day; the others step back from it (every day on 7d, every 5 days on 30d, every other month start on 365d).
  3. English uses a 12-hour clock: 5:36am in the masthead, (5:31am local) in the feed, chart axis and popover, feed hover text. Chinese and Japanese keep 24-hour (05:36, 22:03). The clock pill reads "Local" (capitalized) in English.
  4. Chinese and Japanese follower counts: exact below 10,000 (4,407), then 万 (2.9万), then 亿 / 億 from 100 million. Truncated, never rounded up. Also in hover and screen-reader labels. English stays 29.7k. Formatted on the server.
  5. Shorter pending message: "Language, translation and analysis pending (5-15 min. est.)" (zh 语言、翻译和分析待处理（预计5-15分钟）; ja 言語・翻訳・分析待ち（目安5〜15分）). The retry variant becomes "Analysis pending, retry queued (15 min. est.)" (zh 分析待处理，等待重试（预计15分钟）; ja 分析待ち・再試行待ち（目安15分）). Applies wherever the server sends it: homepage, feed and post-analysis status responses. The zh/ja wording and the retry variant were chosen by the agent and need review.
  6. "Audience topic" reads "Audience Topic" everywhere (for example the hover text "DeepSeek Audience Topic: Cost & Performance").

  2. Japanese chart popover shows 12-hour English times; set the hour format per page language.
  3. Chart drawing squeezed and pointer positions ~20% off, because the canvas height is forced while Chart.js measures the parent (covered by item 31).
  4. Chart legend shows raw brand codes (glm, mimo, llama, stepfun, …) for most brands: pw-chart.js has its own short name list (BRAND_NAMES) that covers only a few brands. Use the brand's display name from the payload instead, as the trending bar does.
