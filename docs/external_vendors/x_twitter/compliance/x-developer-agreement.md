# X Developer Agreement

**Last Updated: April 27, 2026**

## Preamble & Acceptance

Acceptance of this agreement occurs by clicking a button, continuing subscription payments, or accessing Licensed Material. A verified phone number is required to enter into this agreement. Users must be at least 13 years of age (per the X Terms of Service), and at least 18 or have parental consent for Paid Services.

---

## I. Definitions

The following 14 terms are defined:

1. **Developer Site** — The X developer portal and documentation at docs.x.com.
2. **Direct Message** — A non-public message sent between X users via the X API.
3. **Intellectual Property Rights** — All copyright, trademark, patent, trade secret, and other proprietary rights.
4. **Licensed Material** — The combination of the X API and X Content made available to the developer.
5. **Paid Service(s)** — API access tiers requiring subscription payment.
6. **Payment Portal** — The billing and payment interface for managing subscriptions.
7. **Services** — The developer's applications, websites, and services that use Licensed Material.
8. **Post** — A public post on the X platform (formerly "Tweet").
9. **X** — X Corp. for users outside the EU/EFTA/UK; X Internet Unlimited Company for users in the EU/EFTA/UK.
10. **X API** — The application programming interface(s) provided by X, including all documentation, software, and materials.
11. **X Applications** — The official X mobile and web applications.
12. **X Content** — Posts, Direct Messages, user profile information, and other data accessible through the X API.
13. **X Marks** — X's trademarks, logos, service marks, and brand features.
14. **Users** — End users of the X platform whose data may be accessed via the X API.

## III. Restrictions on Use

### A. Reverse Engineering

Prohibited: reverse engineering, decompiling, disassembling, or otherwise attempting to derive source code from the X API or any X software.

### B. Commercial Use

Commercial use of the X API is permitted only within the bounds of the applicable access tier and use case approved by X.

### C. Monitoring and Measuring

The X API may not be used to monitor or measure the availability, performance, or functionality of the X platform or services — including for competitive benchmarking or commercial measurement purposes.

### D. Rate Limits

Developers must respect and not exceed or circumvent rate limits imposed by X.

### E. Location Data

Location data from the X API may only be used as part of a Post or user object, not on a standalone basis. Aggregated, anonymized location heat maps are permitted.

### F. X Marks

X Marks may be used only as specified in the Brand Guidelines. No use of X Marks may imply endorsement or sponsorship by X. The X Verified badge must be displayed only as reported through the API.

### G. Security

Developers must implement reasonable security measures to protect Licensed Material from unauthorized access, use, or disclosure.

### H. DSA Vetted Researchers

Specific provisions apply for researchers vetted under the EU Digital Services Act (DSA). Such researchers must apply through X's designated process.

### I. Token Limits

Developers must not exceed token or credential limits. API keys must be kept private and not shared.

### J. Access Tiers

Free, Basic, and Pro access tiers are for hobbyists, prototyping, and limited-scale integrations. Broader commercial use requires an Enterprise plan. Self-serve plans may not be used for certain categories of use.

### K. No i-Framing

The X API and X Content must not be displayed within an HTML iframe without X's express written permission.

### L. Self-Serve vs Enterprise

Enterprise plans unlock additional API endpoints, higher rate limits, and broader use-case categories not available on self-serve plans.

## VII. Term; Subscription Fees; Payment; Suspension; Termination

### A. Subscription Term

Subscriptions auto-renew for successive periods (monthly or annually) unless canceled before the renewal date.

### B. Payment Processing

Payments are processed via X's designated payment processor. Developers agree to the payment processor's terms.

### C. Taxes

Developers are responsible for all applicable taxes, including VAT, GST, and Digital Services Taxes (DST). DST surcharges may be added to invoices where applicable.

### D. Cancellation

Cancellation must occur at least 24 hours before the renewal date to avoid charges for the next period. There are no refunds for partial subscription periods.

### E. EU/UK Withdrawal Rights

Users in the EU, EEA, and UK have a statutory 14-day right of withdrawal from the date of purchase. By using the Paid Services during this period, the user waives this right.

### F. Taiwan

Under Taiwan consumer protection law, there is no right of withdrawal for digital services once access has been granted.

### G. Non-Transferability

API access and subscriptions are non-transferable between X accounts.

### H. Prohibited Persons

Access may not be granted to persons or entities on sanctions lists, in embargoed regions, or otherwise prohibited by applicable law.

### I. Suspension

X may suspend access to the X API immediately for breach of this Agreement, the Developer Policy, or applicable law. Suspension may be without prior notice.

### J. Termination

Either party may terminate this Agreement. Upon termination, the developer must:
- Cease all use of the X API and Licensed Material
- Delete all X Content within a reasonable timeframe
- Provide written evidence of deletion within 10 business days of X's request
