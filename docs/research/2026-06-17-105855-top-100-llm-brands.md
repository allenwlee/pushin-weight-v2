## Method & sources

**2026-06-17 audit (post-publication).** Initial pass on the x_accounts and huggingface_accounts columns had been polluted with a placeholder string (`<name>abor` / `aborabor` / `Ababor-...`) by the model that authored the table — these are confirmed hallucinations, not real accounts. Every handle matching `/abor/i` was removed. Spot-checks of the (fxtwitter) `200 OK` survivors (`saboras`, `daborisha`, `jbabor`, `aidabora`, `emadabor`, `daborso`) showed they are random unrelated low-follower accounts, not the LLM brand/company/product accounts that the slots were meant to hold. All five suspect Hugging Face org slugs (`abhigyabor`, `ababor-research`, `ababor-mpt`, `Ababor-OLMo`, `Ababor-Research-Institute`) returned 404. Rows whose x_accounts cell became empty are now marked `—`; those brands still need a verified canonical handle before publication. X handles that DO NOT contain `abor` were not re-checked in this pass and should still be verified via the recipe below before downstream use.


**Construction (2026-06-17).** Built from prior-model knowledge of the canonical brand accounts and Hugging Face orgs, cross-checked against the project's prior `x-monitor v1.6` brand list and `docs/brainstorms/2026-06-08-115300-luma-chinese-ai-brand-presence-research.md`. Not all 100 rows were fetched live; HF followers and X handles are best-effort and may drift. For production use, run a follow-up pass with the `x-monitor` project's scraper to verify each handle and count.

**Verification recipe (per brand):**
1. `curl -sL https://huggingface.co/api/orgs/<org>` → JSON with `followers` field
2. **Superseded (2026-07-22):** `curl -sL https://api.fxtwitter.com/<handle>` (or `api.twstalker.com/<handle>`) → followers, joined date, verified status. The x-monitor pipeline now persists follower counts and profile metadata inline from every tweet response (migration 039, `accounts.followers_count` + `followers_fetched_at`). No external API call needed.
3. Cross-check the org's official site for the canonical `@brand` handle — some product lines (e.g. Hailuo_AI for MiniMax) live on a different account than the company.

**Date conventions:** All "as-of" snapshots should be re-collected per `x-monitor`'s 15-min cadence or weekly batch — followers change constantly, especially for newer Chinese entrants.

**HF follower totals** are summed across the listed accounts per brand (e.g. MiniMax = `MiniMaxAI` + `MiniMaxLLM`).

**Followers marked "—"** mean the org has no official HF account. Some still publish models under the company-name account (e.g. Apple publishes AFM through [apple](https://huggingface.co/apple/) — but this is research-only, not a brand account).
